# Nesphere art walkthrough

A working draft: a browser walkthrough of the hotel floors (1/F to 4/F) for planning where screens,
artworks and spotlights go.

Open it here: https://culturevaultsam.github.io/nesphere-walkthrough/

- Drag to look. Click the floor or use W A S D to walk. Use the 1/F to 4/F buttons to change floor.
- The placements shown are a first pass. Changes you make are kept in your own browser only.
- Geometry is traced from 2017 to 2018 coordination drawings and ceiling heights are assumed. See "Read first" in the page.
